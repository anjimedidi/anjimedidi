# Portfolio on GitHub Pages

The website is in `docs/`. The profile README remains separate.

## Publish

1. Commit the `docs` folder to the `main` branch of `anjimedidi/anjimedidi`.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, then **main** and **/docs**, and click **Save**.

The expected URL is **https://anjimedidi.github.io/anjimedidi/**. GitHub will show the confirmed URL in Pages settings once the deployment succeeds.

## Edit

- Content and links: `docs/index.html`
- Layout and visual design: `docs/styles.css`
- Navigation, animations, and project panels: `docs/script.js`
- Images and fonts: `docs/assets/`

The site is static and needs no package installation, API keys, or build step. All visual assets and fonts are local. Links to IEEE, LinkedIn, and GitHub leave the site. Contact opens the visitor's email application.

## Preview locally

Run `python3 -m http.server 4173 --directory docs` from the repository, then visit http://localhost:4173.
